**Summary:**
Starting June 15, 2026, Anthropic is splitting Claude subscription plans into two separate usage pools: an interactive pool (covering claude.ai, Claude Code in the terminal, and Claude Cowork) and a new "Agent SDK Credit pool" covering programmatic usage via the Agent SDK, `claude -p`, Claude Code GitHub Actions, and third-party agent apps such as OpenClaw, Conductor, and Zed.
